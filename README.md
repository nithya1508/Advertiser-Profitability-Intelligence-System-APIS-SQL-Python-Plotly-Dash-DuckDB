# Advertiser Profitability Intelligence System (APIS)

**TL;DR**  
A finance-focused analytics pipeline that evaluates advertiser performance using ROAS, incrementality (iROAS), cohort LTV, and risk scoring — inspired by Google’s Ads Value Accelerator framework.

Built with Python, DuckDB, and Plotly Dash, this project simulates how Product Finance teams assess whether ad spend drives *true incremental value*, not just revenue.

👉 Run the pipeline: `python setup.py`  
👉 Launch dashboard: `python dashboard/app.py`
